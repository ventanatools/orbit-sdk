# Security

This SDK is a preview. Its companion process runs with the Windows user's
permissions; authentication does not sandbox an extension or protect against
every process already running as that user. Install only extensions you trust.

Report suspected authentication, credential handling, framing or package
validation vulnerabilities using this repository's GitHub **Report a
vulnerability** option if available. If that option is unavailable, use the
contact route on https://ventana.tools and request private security coordination.
Do not put vulnerability details or credentials in a public issue.

Include affected versions, a minimal reproduction and expected versus observed
behavior. Use disposable test credentials and synthetic documents. Do not send
real connection info, pairing files, bridge credentials or personal app data.

Only the current preview is actively maintained. Stable version support and
response-time commitments have not been established.
